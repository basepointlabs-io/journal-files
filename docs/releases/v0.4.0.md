**Revit Journal Analyzer** explains Autodesk Revit journal files in plain English and now also watches the computer while Revit runs. It works entirely on your computer: no AI, no uploads.

## What's new in 0.4.0

### See what is going on right now
- **Overview from the tray icon.** A left click on the icon opens a compact panel: overall state (*All good*, *Keep an eye on it*, *Act now*), memory with its curve over the last half hour, processor, disk, and every running Revit with its model, memory, processor share, drawing resources and sync state — plus up to three things to do. **Open full analysis** leads to the main window; a double click on the icon opens it directly.
- **The icon shows the state**: a green, amber or red dot, and a tooltip such as "All good · 1 Revit running · 3.6 GB RAM free".
- **New start screen**: "Right now" on the left, "What's wrong with Revit?" on the right.

### Warnings before something runs out
The app reads the computer's state from Windows every 5 seconds and warns when:
- **memory is low**, or is **falling steadily** ("At this rate memory runs out in about 25 min");
- **Windows is running out of virtual memory** (page file);
- a Revit is close to the **10,000 drawing resources** (GDI/USER objects) Windows allows per program — the point where Revit stops drawing its windows and can crash;
- a **drive is almost full**;
- **several Revit windows** together use most of the memory.

It also tells a Revit that is **busy** (not answering clicks but working) from one that is **stuck** (not using the processor).

Only running out of resources can be foreseen this way. A crash caused by a bug or a damaged element gives no such warning.

### Faster and lighter
- **Results are remembered.** A finished session is analyzed once and then read from a small cache in `%LOCALAPPDATA%\RevitJournalAnalyzer\cache`; on a test PC opening 139 journals went from 5 s to 0.1 s. **Refresh** reads the journals again. The cache stays on the computer and is removed by the uninstaller.
- **Worker logs are checked too**: lines from `journal.NNNN.worker1.log` appear in findings as `worker1:<line>`.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads Revit's journals in `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`, the Windows Application event log (for crash proof) and the computer's resource counters. Nothing is sent anywhere.

## Known limitations

- The warnings about memory, drawing resources and disk are covered by automated tests; please report how they behave during real work.
- The number of open views and the warnings inside a model are not read yet.
