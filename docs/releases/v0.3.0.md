**Revit Journal Analyzer** explains Autodesk Revit journal files in plain English: what happened, why, and what to do — down to the element, view and model involved. It runs entirely on your computer: no AI, no uploads.

## Download

| File | For |
|---|---|
| **RevitJournalAnalyzer-0.3.0-setup.exe** | Recommended. Installs for the current user (no admin rights), adds a Start menu shortcut and can start with Windows to watch Revit in the background. Works on ordinary (x64) and ARM PCs. |
| RevitJournalAnalyzer-0.3.0-portable-x64.exe | Single file, no installation, for ordinary Windows PCs. |
| RevitJournalAnalyzer-0.3.0-portable-arm64.exe | Single file, no installation, for ARM PCs (e.g. Windows on Mac). |

> The files are not code-signed yet. Windows SmartScreen may say "Windows protected your PC": click **More info → Run anyway**.

## What it does

- **"What's wrong with Revit?"** — pick a symptom (crashed, won't sync, slow / not responding) and get the answer for the relevant session of the Revit version you choose.
- **Concrete, element-level advice** — e.g. *you were dragging the end of duct 1234567 onto element 1234568 in view "Floor Plan: …"*, with Select by ID steps; orphaned tags on links with their IDs; failed Synchronize with Central with save-first recovery steps and the amount of unsynchronized work.
- **Live monitoring** — a tray icon follows every running Revit and shows a Windows notification when a sync fails, a sync takes over 10 minutes, memory runs low, Revit stops responding or closes unexpectedly. Clicking it opens the answer.
- **All sessions** of every installed Revit version in the sidebar, grouped by day, with a full report for each and a warning when Revit crashed repeatedly during the week.
- **Knowledge base** of 150+ rules from Autodesk Help, the Autodesk Community and real journals, including common Revit warnings matched in any UI language.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads the journals Revit writes to `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`. Tested with Revit 2025, 2026 and 2027.

## Known limitations

- Journals do not contain element IDs for Revit warnings; those findings lead to *Manage → Review Warnings*.
- Workaround advice (e.g. "delete and redraw the element") is marked as community advice, not an Autodesk-confirmed fix.
- Live alerts for failed syncs and "not responding" are covered by automated tests; please report how they behave on your projects.
