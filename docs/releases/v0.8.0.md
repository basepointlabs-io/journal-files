**Revit Doctor** watches the computer while Revit runs and explains Revit journal files in plain English. It works entirely on your computer: no AI, no uploads. From the internet it reads only two public pages: Autodesk's service status and this project's latest release on GitHub.

## What's new in 0.8.0

### Updates from the app
- Once a day Revit Doctor checks GitHub for a newer version. When one is published, a notification appears once and the overview shows what is new.
- **Install update** downloads the new installer, checks it against the release's checksum (`SHA256SUMS`) and installs it silently; the new version then starts in the tray. Switch the check off in the tray menu ("Check for updates").
- This works from 0.8.0 on: if you have 0.7.3 or older, install this version once by hand.

### Journals of a Revit in any language
- Rules now recognise Revit's dialogs by their id, which is the same in every language, and messages without an id in Revit's own German, French, Spanish, Italian and Portuguese wording. A German "Nicht genügend Speicher." is now explained like "Out of memory.".
- The serious-error dialog in its current wording ("Revit encountered a serious error") is recognised.

### 36 new findings from Autodesk articles
- Every new finding comes from an Autodesk Help or support article that names the journal message, with the article linked; every step was checked against the article's text.
- Among them: Revit running out of memory during a sync (MemoryException), corrupt data read from the central model (ArchiveException 105), hardware I/O errors, failed backups before saving, unresolved references, "Can't edit the element until ... resaves", "You now own the element, but your file is out of date", sync and save reminders, missing third-party updaters, add-in signing prompts, cloud model access and common geometry and room warnings.
- "Revit ran out of memory" now rests on Autodesk articles instead of forum posts.

### This computer and Autodesk's figures
- The start screen shows RAM, free disk, space for cloud models, page file and video memory as bars, with Autodesk's figures as marks and a link to the article for each. The RAM bar also shows the memory in use now.
- The page file line explains what a page file is and warns when Windows is short of memory (RAM + page file).
- The three tiles are shown only in the tray overview; the start screen has the bars instead. Long figures in the tiles shrink to fit.

### RAM needed
- "RAM needed" is Autodesk's 20 × the RVT files opened, **including linked files**, as Autodesk's article on the memory warning counts them. Links that are not on this computer cannot be counted, and the overview says so.
- Models opened without worksharing now get a "RAM needed" figure too.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads Autodesk's public status page (health.autodesk.com) every 5 minutes and this project's latest release on GitHub once a day; without an internet connection everything else works as before.
- Reads Revit's journals in `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`, the Windows Application event log (for crash proof), the computer's resource counters, the size of model files on this computer and the graphics card's memory from the Windows registry. Nothing is sent anywhere.

## Known limitations

- Translated message phrases cover German, French, Spanish, Italian and Portuguese; for Czech, Polish, Russian, Japanese, Korean and Chinese only dialog ids are recognised.
- Sizes of linked models are known only on the computer the journal comes from.
- The installer is not code-signed yet, so an update is protected by its checksum, not by a signature.
- "RAM used" is the memory Revit has taken (private bytes); Task Manager may show a little less.
