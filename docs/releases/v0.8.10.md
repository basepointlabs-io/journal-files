**Revit Doctor** watches the computer while Revit runs and explains Revit journal files in plain English. It works entirely on your computer: no AI, no uploads. From the internet it reads only two public pages: Autodesk's service status and this project's latest release on GitHub.

## What's new in 0.8.10

### Crashes from running out of memory are named as crashes
- A journal that ends with "A MemoryException is raised" is now reported as **Revit crashed: it ran out of memory and stopped there**. Before, such a session was described as ending without a crash record.

### No false alarm when you cancel opening a cloud model
- Pressing **Cancel** while opening a cloud model (for example on "You have made changes that have not been synchronized") is no longer reported as "Cloud model could not be opened due to internet connection".

### More journal messages explained, from Autodesk articles
- **"Failed to initialize the add-in ... because the assembly ... does not exist"**: an add-in's DLL is missing; how to update Revit, correct the path in the .addin file, or reinstall or remove the add-in.
- **"The Tap must be attached to duct"**: why it happens with elements hosted on linked models, and how to find and reconnect the elements.
- **"The segment is being drawn from the wrong side to connect to the location you indicated"**: the flow direction or placement of a fitting family's connector.
- **"There was not enough room to place the required fittings"**: short segments, offset differences and back-to-back elbows.
- **"The References of the highlighted Dimension are no longer parallel"**: export the warnings, review the elements, recreate the dimensions.
- **"There is no open view that shows any of the highlighted elements"**: check the add-ins.

All six are also recognised in German, French, Spanish, Italian and Portuguese Revit.

### Updating
- If you have 0.8.0 or later, click **Install update** in the overview. From 0.7.3 or older, install this version once by hand.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads Autodesk's public status page (health.autodesk.com) every 5 minutes and this project's latest release on GitHub once a day; without an internet connection everything else works as before.
- Reads Revit's journals in `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`, the Windows Application event log (for crash proof), the computer's resource counters, the size of model files on this computer and the graphics card's memory from the Windows registry. Nothing is sent anywhere.

## Known limitations

- Crash code 0xe06d7363 is not explained: Autodesk documents it only for cloud model crashes.
- The installer is not code-signed yet, so an update is protected by its checksum, not by a signature.
