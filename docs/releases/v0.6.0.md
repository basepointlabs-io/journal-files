**Revit Doctor** watches the computer while Revit runs and explains Revit journal files in plain English. It works entirely on your computer: no AI, no uploads.

## What's new in 0.6.0

### A clearer "Right now"
- **Three tiles** instead of the large chart: **Free RAM** (with the last half hour as a small curve), **Free disk space** and **Revit open**. Each figure says what it is measured against: "of 31.5 GB · fell 4.0 GB in 29 min", "Autodesk requires at least 30 GB", "using 24.0 GB of RAM".
- **One table for every running Revit**, with dividers between the columns: Model (with the Revit version and what it is doing), RAM used, RAM needed, Model file, Linked models (number and size) and Open views. The tray window shows the model and the two RAM columns.
- Everywhere the app means RAM it now says **RAM**, so RAM and file sizes no longer look alike.
- The time of the last synchronization is no longer shown; a failed synchronization still appears as a red line under its Revit.
- The window is wider (1100 px) so that every column fits.

### RAM needed: Autodesk's 20× rule
- The comparison now follows Autodesk's **Memory Recommendations: RAM required is about 20 times the size of the compacted central file**. The table of 16 / 32 / 64 GB from the system requirements is no longer used; it put any model over 600 MB in the 64 GB row.
- **Linked models are added as an estimate.** Autodesk gives the 20× figure for the project file only; Revit Doctor applies the same factor to the linked models it finds on this computer and always labels that figure as an estimate. The report shows both: Autodesk's figure for the model and the estimate with links.
- The same applies when several models are open in several Revits at once.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads Revit's journals in `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`, the Windows Application event log (for crash proof), the computer's resource counters and the size of model files on this computer. Nothing is sent anywhere.

## Known limitations

- The new layout is covered by automated tests and rendered screens with sample figures; please report how it behaves during real work.
- RAM needed with linked models is an estimate: Autodesk does not say how linked models add to the 20× figure.
- Sizes of linked models are known only on the computer the journal comes from, and links stay counted until that Revit is closed.
- "RAM used" is the memory Revit has taken (private bytes); Task Manager may show a little less.
