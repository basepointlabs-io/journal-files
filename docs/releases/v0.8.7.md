**Revit Doctor** watches the computer while Revit runs and explains Revit journal files in plain English. It works entirely on your computer: no AI, no uploads. From the internet it reads only two public pages: Autodesk's service status and this project's latest release on GitHub.

## What's new in 0.8.7

### A new look
- The app is drawn like a drawing sheet: pale blue paper, dark text, one blue accent and a monospaced font.
- The dials are now straight scales. The coloured zones and the numbers under a scale are Autodesk's figures, and the pointer above it is this computer.
- The tray overview has one button into the full window, **Open full analysis**, and a link to basepointlabs.io.

### Add-ins that fail or slow the start
- **An add-in that failed to start** now says so when it was built for an older .NET than Revit runs on. Revit 2025.5 and 2026.5 are built on .NET 10, and Autodesk warns that add-ins not updated for it may fail to load. The steps are Autodesk's: reinstall or update the add-in, ask its maker for a .NET 10 version, check for a conflict with another add-in.
- **A slow start** names the add-in that took longest to load, when the journal's timestamps prove it. The steps are from Autodesk's "Slow start up in Revit": the Loading Time column in the Add-Ins Manager, the Recent Files list in Revit.ini, updates.

### More journal messages explained, from Autodesk articles
- **"Some data in file ... needs to be recovered. In the Open dialog, select the Audit option"** (CArchiveException 105 in the journal).
- **"Revit cannot import some of the geometry"** when linking or importing a DWG.

### Updating
- If you have 0.8.0 or later, click **Install update** in the overview. From 0.7.3 or older, install this version once by hand.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads Autodesk's public status page (health.autodesk.com) every 5 minutes and this project's latest release on GitHub once a day; without an internet connection everything else works as before.
- Reads Revit's journals in `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`, the Windows Application event log (for crash proof), the computer's resource counters, the size of model files on this computer and the graphics card's memory from the Windows registry. Nothing is sent anywhere.

## Known limitations

- Crash code 0xe06d7363 is not explained: Autodesk documents it only for cloud model crashes.
- The installer is not code-signed yet, so an update is protected by its checksum, not by a signature.
