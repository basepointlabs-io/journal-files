**Revit Doctor** watches the computer while Revit runs and explains Revit journal files in plain English. It works entirely on your computer: no AI, no uploads. The only thing it reads from the internet is Autodesk's public service status.

## What's new in 0.7.0

### Autodesk service status
Revit Doctor now tells you when the problem is on Autodesk's side, not on your computer.
- Every 5 minutes it reads the **Autodesk Health Dashboard** (health.autodesk.com) for the services Revit uses in the **European Union**: Revit Cloud Worksharing / Cloud Models, BIM 360 Docs, BIM 360 Design Collaboration, and sign-in and licensing.
- **When a problem starts**, a Windows notification appears: which service, since when, Autodesk's latest update, and "This is not your computer." Click it to open the incident on Autodesk's page. A second notification says when the problem is resolved.
- **While it lasts**, the overview shows an "Autodesk services (EU)" panel with a link to the incident, and the tray icon turns amber.
- **A sync that fails** while Autodesk reports a problem with Revit Cloud Worksharing says so in its notification.
- When everything works, one quiet line at the bottom of the overview says so, together with any maintenance Autodesk has announced.

This is the app's only network request: a plain read of a public page. Nothing about your computer, your user name or your models is sent. Without a connection (or behind a firewall that blocks it) the overview says the status could not be checked, and everything else works as before.

## Requirements

- Windows 10 or 11, x64 or ARM64. Nothing else to install (.NET is included).
- Reads Autodesk's public status page (health.autodesk.com) every 5 minutes; without an internet connection everything else works as before.
- Reads Revit's journals in `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 20XX\Journals`, the Windows Application event log (for crash proof), the computer's resource counters and the size of model files on this computer. Nothing is sent anywhere.

## Known limitations

- The new layout is checked with automated tests and rendered screens with sample figures; please report how it behaves during real work.
- RAM needed with linked models is an estimate: Autodesk does not say how linked models add to the 20× figure.
- Sizes of linked models are known only on the computer the journal comes from, and links stay counted until that Revit is closed.
- "RAM used" is the memory Revit has taken (private bytes); Task Manager may show a little less.
